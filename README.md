# azizurrahmanbhuiyan.github.io

Root GitHub Pages site. It exists so Android can verify the FamilyEnglish app:
`/.well-known/assetlinks.json` links the Play Store app
(`io.github.azizurrahmanbhuiyan.familyenglish`) to
https://azizurrahmanbhuiyan.github.io/FamilyEnglish/ so it opens full screen,
without a browser address bar. `.nojekyll` makes GitHub Pages publish the
`.well-known` folder. The home page forwards to the app.
